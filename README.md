# Proyecto de Integración de API

Este repositorio contiene 4 programas independientes que consumen APIs de diferentes categorías:

- **social-api**: Obtiene las historias más populares de Hacker News (reemplazo de Reddit).
- **streaming-api**: (próximamente) Busca videos en YouTube.
- **data-api**: (próximamente) Muestra la imagen astronómica del día de la NASA.
- **geolocation-api**: (próximamente) Consulta el clima actual de una ciudad (OpenWeatherMap).

## Requisitos previos
- Node.js (v14 o superior)
- npm
